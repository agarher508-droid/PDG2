# CEIP Toxiria · Plan de Centro 2026/27

Web estática preparada para GitHub Pages.

## Archivos
- `index.html`: estructura y contenido de la web.
- `style.css`: diseño y responsive.
- `script.js`: buscador, filtros, desplegables y copia de referencias.
- `assets/escudo.png`: escudo utilizado en la web.

## Publicar en GitHub Pages
1. Crea un repositorio, por ejemplo `ceip-toxiria-plan-centro`.
2. Sube **todo el contenido de esta carpeta**, no la carpeta contenedora.
3. En GitHub entra en **Settings → Pages**.
4. En **Build and deployment**, selecciona `Deploy from a branch`.
5. Selecciona `main` y `/ (root)` y pulsa **Save**.
6. GitHub generará la dirección pública de la web.

La página no necesita servidor: funciona como HTML/CSS/JavaScript estático.
